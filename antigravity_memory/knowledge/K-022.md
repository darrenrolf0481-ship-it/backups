# K-022 — cookie-authentication-fix-for-notebooklm

tags: cookies, auth, bugfix
confidence: 0.9
created: 2026-09-07T13:35:15.422Z

Cookie authentication fix for NotebookLM: Netscape cookie export contains cookies from Gmail, YouTube, Mozilla etc. When browser.py _try_parse_netscape_cookies() parses, it flattens all domains into single dict. YouTube cookies for HSID/SSID overwrite .google.com versions causing auth redirect. Fix: filter to .google.com + notebook.google.com domains only. Clean cookies at /root/backups/clean_notebook_cookies.txt.
